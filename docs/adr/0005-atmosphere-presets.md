# 0005. Свет, небо и погода — пресет атмосферы на карту

## Контекст

Солнце, небо, туман и экспозиция заданы константами при создании рендерера, погоды нет, а в сцене нет источников света, кроме солнца, полусферы и четырёх динамических огней эффектов. Добавление источника в рантайме перекомпилирует все шейдеры.

## Решение

У каждой карты есть пресет атмосферы (солнце, небо, туман, окружение, экспозиция, цветокоррекция, погода, ночь), который применяется при смене карты. Ночь строится из излучающих фонарей и вывесок плюс не более четырёх точечных источников возле игрока, переставляемых по ближайшим фонарям. Число источников меняется только внутри применения пресета, на экране загрузки.

## Почему

- Много настоящих источников света на фонарь отвергнуто: в прямом рендеринге WebGL их стоимость растёт с каждым источником на каждом пикселе.
- Менять число источников по ходу игры отвергнуто: каждое изменение перекомпилирует программы и даёт рывок в бою.
- Один общий вид для всех карт отвергнут: тема (снег, дождь, пыль, ночь) — главное, чем карты должны отличаться.
- Пресет `block` берёт числа прежнего вида, так что «Квартал» не меняется без нужды.

## Последствия

- Смена атмосферы пересобирает карту окружения, а это сотни миллисекунд внутри экрана загрузки.
- Ночь ограничена: за пределами четырёх источников свет только «нарисован» свечением, и его видно лишь через порог свечения.
- Числа оружейной сцены перестали быть константами и следуют пресету; ошибка в пресете ломает вид рук игрока.
- Для «Квартала» пресет изменён сознательно (туман, рассеяние), поэтому тест атмосферы больше не сверяет его со старыми константами.
