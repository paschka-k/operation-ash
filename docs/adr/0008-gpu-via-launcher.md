# 0008. Выбор видеокарты — только через лаунчер

## Контекст

Игра на ноутбуке рисует на встроенной Intel Iris Xe, хотя есть RTX 4070. Опыт 20.11 на машине пользователя: в обычной вкладке Chrome и Edge отдают странице Intel при любом `powerPreference`, и для WebGL, и для WebGPU. С отдельным профилем и ключом `--force_high_performance_gpu` оба отдают RTX 4070.

## Решение

Игру запускает лаунчер на Node без зависимостей (`npm run play` или `play-windows.cmd`): он поднимает сервер на 127.0.0.1, находит Chrome или Edge и открывает окно `--app` с нужным ключом. Выбор из настроек игры сохраняется и перезапускает окно. В обычной вкладке пункт показывает видеокарту и честно говорит, как получить выбор.

## Почему

- Запросить видеокарту из страницы (`powerPreference`) отвергнуто: проверено, не работает.
- Перейти на WebGPU-рендерер отвергнуто: выбор видеокарты он не даёт (проверено), а перепись теней и постэффектов — отдельная волна.
- Настольное приложение (Electron, Tauri) отвергнуто: нужна загрузка, а лаунчер на установленных Chrome или Edge и Node даёт то же без загрузок.
- Оставить подсказку про настройки Windows одним путём отвергнуто: пользователь прямо просил не лезть в эти настройки; подсказка осталась вторым путём.

## Последствия

- На сайте и в `dist/game.html` выбора нет и не будет; игра говорит это прямо.
- Проверена только Windows-машина пользователя; пути Chrome на macOS и Linux пробуются, но не проверены.
- Выбор требует перезапуска окна: допустим только в меню и на паузе, а не в бою.
- Игра узнаёт о лаунчере пробой на localhost; на Pages и `file://` проба должна проваливаться тихо.
- Если ни Chrome, ни Edge нет, лаунчер открывает игру браузером по умолчанию и говорит, что выбирать нечем.
