## Что должно заработать

Игрок запускает игру лаунчером — `npm run play` или двойным щелчком по `play-windows.cmd` — и получает окно игры без панелей браузера. В настройках пункт «Видеокарта» со списком видеокарт его системы; выбрал другую — окно перезапускается, и игра рисует уже на ней. Никаких настроек Windows и браузера. В обычной вкладке (сайт, `dist/game.html`) пункт честно показывает, на какой видеокарте игра рисует и как получить выбор.

Факт, проверенный 20.11 на машине пользователя (RTX 4070 Laptop + Intel Iris Xe): Chrome 157 и Edge 157 с отдельным `--user-data-dir` и ключом `--force_high_performance_gpu` отдают WebGL и WebGPU RTX 4070; без ключа — Intel; страница в обычной вкладке выбрать не может.

## Критерии приёмки

- [ ] `npm run play` и `play-windows.cmd`: сервер на 127.0.0.1 (свободный порт от 5180), окно Chrome (иначе Edge) `--app` с профилем `%LOCALAPPDATA%\OperationAsh\browser`; без Chrome и Edge — одна строка в консоли и игра в браузере по умолчанию; закрыл окно — лаунчер завершился
- [ ] `GET /launcher/info` отдаёт видеокарты системы по именам (`Win32_VideoController`) с видами и текущий выбор; `POST /launcher/gpu` с чужим `Origin` — 403; со своим — выбор сохранён в `%LOCALAPPDATA%\OperationAsh\launcher.json`, окно перезапущено с ключом или без
- [ ] Проверено на этой машине: выбор «NVIDIA … — быстрая» → строка рендерера WebGL в игре называет NVIDIA; выбор «по выбору Windows» → Intel; после перезапуска лаунчера выбор прежний
- [ ] Пункт «Видеокарта» в настройках: под лаунчером — `select#s-gpu`; во время боя недоступен с подсказкой «на паузе»; перед перезапуском настройки сохранены, окно открывается в главном меню
- [ ] В обычной вкладке (`npm start`, без лаунчера): пункт показывает видеокарту и текст: браузер сам выбирает видеокарту, выбрать её в игре можно, запустив игру лаунчером из папки игры; прежняя подсказка про Windows остаётся; на `file://` и при 404 проба тихая, без ошибки в консоли
- [ ] Лаунчер не пишет в реестр и не меняет профиль и флаги обычного браузера пользователя; ничего не скачивает (проверка по коду: только `child_process` на найденный exe и PowerShell `Get-CimInstance` для списка)
- [ ] `tests/tools/launch.test.mjs`: `browserArgs`, `gpuOptions`, `originAllowed`, `findBrowser`; `npm run test:tools` гоняет все `tests/tools/*.test.mjs`; `npm start` работает как раньше
- [ ] README: раздел про запуск лаунчером и выбор видеокарты; строки ru/en
