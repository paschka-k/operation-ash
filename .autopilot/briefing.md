# Брифинг: допущения и решения

Интервью невозможно: пользователь не отвечает по ходу работы. Каждый открытый вопрос закрыт допущением (G) или решением (D). Любое можно оспорить.

## Допущения

| №   | Допущение | Почему |
|-----|-----------|--------|
| G01 | Платформа: браузер, WebGL2, Three.js. `npm start` или один файл `dist/game.html`. | Unreal Engine 5 не поставить из одного диалога. Браузер запускается на любой машине. |
| G02 | «Уровень UE5» означает максимум, достижимый в WebGL: PBR, освещение по изображению, каскадные тени, GTAO, bloom, SMAA, плёночный тональный отображатель, туман, зерно. Nanite и Lumen недостижимы. | Честная граница. R03 и R16 выполняются в пределах платформы. |
| G03 | «Автомат» это штурмовая винтовка с автоматическим огнём. | В брифе «пистолет и автомат» чаще означает автоматическое оружие. |
| G04 | Режим: выживание волнами против ботов на разрушенном квартале. Десять волн, затем бесконечный режим. | Бриф просит игровые механики, но не режим. Десять волн и бесконечный режим пришли из уточнений. |
| G05 | Названия оружия и мира вымышленные. | Не использовать чужие торговые марки. |

## Решения

| №   | Решение | Причина |
|-----|---------|---------|
| D01 | Модели, текстуры и звуки по умолчанию процедурные. Фотосканы Poly Haven подключаются, если лежат в `assets/`. | Игра работает без сети. Скачивание сторонних файлов требует согласия пользователя, поэтому скрипты запускает он. |
| D02 | `src/core` единственный шов для тестов, чистый, время и случайность параметрами. | Правила проверяются под обычным Node за секунды. |
| D03 | Сетка навигации 0.5 м с полем 0.4 м. | При клетке 1 м и поле 0.45 м двери шириной до 3 м были закрыты для ботов. |
| D04 | Статика уровня склеивается по материалу и куску карты 30 м, тени рисуются один раз за кадр. | Замер: кадр 27 мс до, 21 мс после. Куски карты дают ещё 10 процентов на тяжёлых видах. |
| D05 | Язык по умолчанию русский, переключатель на английский. | Бриф написан по-русски. |
| D06 | Документы процесса порождаются из `.autopilot/data.mjs`. | Один источник правды, ворота проверяются командой. |

## Что осталось за пределами

- Фактическая загрузка фотосканов: нужно явное согласие пользователя (E11-3).
- Звук проверен только чтением кода (E08-7).
- Двойной щелчок по `dist/game.html` по схеме `file://` в панели браузера проверить нельзя (E10-2).
