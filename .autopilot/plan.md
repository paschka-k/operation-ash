# План: волны задач

Проект не под git, поэтому коммитов нет. Состояние задач в `state.json` и на `dashboard.html`.

Волна 1. Ядро (чистые правила, без рендера)
- T01 математика, коллизии, рейкаст (`src/core/math.js`, `collision.js`)
- T02 навигация и укрытия (`nav.js`, `cover.js`)
- T03 таблицы и формулы (`rules.js`), арсенал (`weapons.js`), бой (`combat.js`)
- T04 ИИ ботов (`ai.js`), волны и счёт (`waves.js`)
- T05 юнит-тесты `tests/core` (112)

Волна 2. Рендер и материалы
- T06 рендерер, небо, каскадные тени, постобработка (`src/render/pipeline.js`)
- T07 процедурные PBR-наборы и загрузчик фотосканов (`materials.js`, `models.js`)
- T08 пресеты качества и автоснижение (`config.js`, `main.js`)

Волна 3. Мир
- T09 карта, здания, укрытия, коллайдеры (`src/world/level.js`)
- T10 уличная мебель, интерьеры, детали выше глаз (`details.js`)
- T11 мелкие объекты инстансингом (`scatter.js`)
- T12 предметы, ящики, бочки, подбор (`props.js`), эффекты (`effects.js`)

Волна 4. Игрок, оружие, враги
- T13 игрок и ввод (`src/player`)
- T14 оружие в руках и стрельба (`src/weapons`, `src/game/shooting.js`)
- T15 боты вокруг ядра ИИ (`src/enemies/squad.js`), директор волн (`src/game/director.js`)

Волна 5. Интерфейс и сборка
- T16 HUD, меню, звук (`src/ui`, `src/audio`)
- T17 цикл игры (`src/main.js`), сервер, сборка одного файла (`tools/build.mjs`)

Волна 6. Проверка
- T18 проверка в браузере: оружие, волны до победы, бесконечный режим, смерть и перезапуск, пауза, F3, звук, прицел, предметы, укрытия ботов, плотность объектов, замеры кадра
- T19 процесс: `data.mjs`, ворота, дашборд, интерфейсы
- T20 независимая проверка спецификации, ревью кода, слепая приёмка субагентами
- T21 исправления по замечаниям

Отложено до согласия пользователя
- T22 загрузка фотосканов Poly Haven (`npm run textures`, `npm run models`)
